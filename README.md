# ALGO VISUALIZER

A Python Tkinter based Sorting Visualizer for DSA algorithms.

## Features
- Bubble Sort
- Selection Sort
- Insertion Sort
- Animated Visualization
- Random Array Generator

## Tech Stack
- Python
- Tkinter

## How to Run

```bash
python VISUALIZER.py
```
